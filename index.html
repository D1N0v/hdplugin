HDRezka для Lampa

Додайте адресу цього файлу до розширень Lampa:

hdrezka.js

Після перезапуску відкрийте Налаштування → HDRezka → Адреса сервера та введіть адресу свого сервера.

GitHub Pages розміщує плагін. Для пошуку та відео потрібен окремий сервер HDRezka. HTTPS-оболонка Lampa може вимагати HTTPS і для цього сервера.
